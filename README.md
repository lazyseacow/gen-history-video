# gen-history-video

面向 DSH 等支持文件型 Agent Skills 的助手，为**手绘风格历史科普视频**提供史实追踪、风格一致性、分镜和本地动画合成规范。

Skill 名称：`history-handdrawn-video`。

> 默认以手绘插画、二维动画与运镜、配音字幕和本地剪辑合成制作视频。本仓库提供指令、参考文档和模板，不内置完整渲染程序；执行时复用当前已安装、已审阅的绘制、声音和合成工具。

## 能做什么

- **统一系列风格**：锁定线条、色板、纸张纹理、人物比例、构图和运动规范；已有品牌规范时只补视频层增量。
- **追踪历史依据**：为关键主张记录来源、定位、核验状态和争议；区分历史事实与艺术复原。
- **编排可执行的分镜**：每镜一个主要信息点，记录素材图层、绘制说明、动画关键帧、运镜和字幕时间轴。
- **指导本地制作**：复用或绘制插画，以推拉平移、分层视差、描边显现和局部动作组织画面，再用 FFmpeg 或现有渲染器合成。
- **分项验收**：分别检查史实、静态画风、动画连续性、旁白、字幕和实际输出。

复用同一角色和场景资产有助于保持一致。程序绘制也需固定纸纹与随机参数，避免逐帧闪烁；没有实际视频查看能力时，动画与时间一致性必须标为未验证。

## 安装到 DSH

将仓库放入 Skill 发现目录，保留目录结构。以下示例使用用户级目录；若目标目录已存在，先检查已有内容，不覆盖。

### Windows PowerShell

```powershell
git clone https://github.com/lazyseacow/gen-history-video.git "$env:USERPROFILE\.agents\skills\history-handdrawn-video"
```

### macOS / Linux

```bash
git clone https://github.com/lazyseacow/gen-history-video.git ~/.agents/skills/history-handdrawn-video
```

在 DSH 中确认技能目录已被发现；若列表未更新，按所用版本的加载方式重新载入或开启新会话。其他 Agent 宿主请按其文件型 Skill 的安装规则使用根目录的 [SKILL.md](SKILL.md)。

安装只提供 Skill 文档，不安装渲染依赖或配置凭据。仅策划不需要执行环境；本地制作需核实绘图、字体、配音及编码能力，具体工具按现有环境选择。

## 快速开始

```text
使用 history-handdrawn-video。
本期想解释唐代科举中的一个具体问题，面向普通观众，使用简体中文。
先帮我缩小题目，整理史实待查清单，并提出一个手绘风格草案。
选题与风格确认后，做 4 个分镜，并用本地工具制作一个含配音、字幕的动画小样。
优先复用已有素材和工具；缺少必要依赖请先说明，不调用付费服务。
无法核实的资料请标为待核验。
```

如果已有系列规范、插画或录音，提供其位置、版本和使用权说明，要求沿用。已有明确题目时，可填写 [单期简报模板](templates/episode-brief.md)。只要本地制作能力齐备，成片制作不需要视频模型、API 密钥或额外订阅。

## 推荐制作流程

```text
选题与范围
  → 史实主张和来源
  → 风格规范及代表画面确认
  → 旁白与动画分镜
  → 手绘素材、角色和场景图层
  → 配音与字幕时间轴
  → 本地二维动画、运镜和合成小样
  → 人工审阅
  → 扩展整期并导出成片
  → 史实、视听和文件检查
```

默认使用已有授权素材、程序绘制或用户提供的插画，配音优先使用用户录音或已安装且授权适用的本地 TTS。外部图片或语音服务只是按需选项，使用前另行确认上传许可与费用。

字幕、年代、地名和精确地图标签由可控的后期排版处理。根据实测旁白长度安排镜头、关键帧和字幕；先通过一个小样，再决定是否扩展整期或批量制作。缺少声音来源时可先交付明确标注的静音画面小样，不把它写成完整成片。

## 工具与授权

优先复用合适的现成组件。可选的 `brand`、`design` 等 Skill 不是必需依赖；没有它们时仍可手动维护本 Skill 要求的规范，也不要求为了短片新建整套前端工程。

第三方候选不是已验证的兼容列表，采用前分别核对来源、版本、许可证、运行环境和隐私条款。参考图、字体、配音、音乐及模型输出的使用权需单独确认；外部付费调用还需核对金额预算与计费规则。

历史来源和素材授权由使用者审查。自动渲染不替代史实核验、完整视频播放或平台发布规则检查。
