# gen-history-video

面向 DSH 等支持文件型 Agent Skills 的助手，为**手绘风格历史科普视频**提供策划、风格一致性、史实追踪和分镜规范。

Skill 名称：`history-handdrawn-video`。

> 这是内容与美术指导 Skill，当前提供指令、参考文档和模板。它不包含视频模型连接器，也不会因安装而自动调用付费服务。实际生成需另接已审阅的 API、CLI、MCP 或插件工具。

## 能做什么

- **统一系列风格**：锁定线条、色板、纸张纹理、人物比例、构图和运动规范；已有品牌规范时只补视频层增量。
- **追踪历史依据**：为关键主张记录来源、定位、核验状态和争议；区分历史事实与艺术复原。
- **编排可生成的分镜**：每镜一个主要信息点和一个清晰动作，输出首帧图片提示词、视频动作提示词与参考素材要求。
- **约束执行成本**：真实调用前核对模型能力、金额与币种预算，保存远端任务 ID，避免结果不明时重复提交。
- **分项验收**：分别检查史实、静态画风、时间一致性、旁白、字幕和执行状态。

提示词、参考图和固定随机种子都不是人物或画风完全一致的保证。没有实际视频查看能力时，时间一致性必须标为未验证。

## 安装到 DSH

将仓库放入 Skill 发现目录，保留目录结构。以下示例使用用户级目录；若目标目录已存在，先检查已有内容，不覆盖。

### Windows PowerShell

```powershell
git clone https://github.com/lazyseacow/gen-history-video.git "$env:USERPROFILE\.agents\skills\history-handdrawn-video"
```

### macOS / Linux

```bash
git clone https://github.com/lazyseacow/gen-history-video.git ~/.agents/skills/history-handdrawn-video
```

在 DSH 中确认技能目录已被发现；若列表未更新，按所用版本的加载方式重新载入或开启新会话。其他 Agent 宿主请按其文件型 Skill 的安装规则使用根目录的 [SKILL.md](SKILL.md)。

只做文本策划不需要视频 API 密钥。安装命令不会安装生成依赖，也不会配置凭据或创建视频任务。

## 快速开始

```text
使用 history-handdrawn-video。
本期想解释唐代科举中的一个具体问题，面向普通观众，使用简体中文。
先帮我缩小题目，整理史实待查清单，并提出一个手绘风格草案。
选题与风格确认后，再做 4 个分镜。
暂不调用付费模型；无法核实的资料请标为待核验。
```

如果已有系列规范或参考图，提供其位置、版本和使用权说明，要求沿用。不要在对话中发送 API 密钥。

已有明确题目时，可填写 [单期简报模板](templates/episode-brief.md)。模型和预算只在准备进入真实生成时确认，不妨碍先做文本规划。

## 推荐制作流程

```text
选题与范围
  → 史实主张和来源
  → 风格规范及参考图确认
  → 旁白与分镜
  → 各镜头手绘首帧
  → 图生视频轻动作小样
  → 人工审阅
  → 配音、字幕与剪辑
  → 成片检查
```

字幕、年代、地名和精确地图标签优先后期制作。先通过一个小样，再决定是否扩展整期或批量制作。

## 外部工具与授权

优先复用合适的现成生成工具。可选的 `brand`、`design` 等 Skill 不是必需依赖；没有它们时仍可手动维护本 Skill 要求的规范。

第三方候选不是已验证的兼容列表，接入前分别核对来源、版本、许可证、接口、费用和隐私条款。参考图、字体、配音、音乐及模型输出的使用权也需单独确认。

历史来源和素材授权由使用者审查。自动生成不替代史实核验、完整视频播放或平台发布规则检查。
