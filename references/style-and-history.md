# 手绘风格与历史准确性规范

本规范是视频专用的补充字段。已有系列品牌规范时，记录源位置与版本，色板、排版、基础提示词只引用原规范；视频层只存运动、角色及历史依据等增量。需要完整审阅时可生成标有源版本的只读快照，不建立第二个可编辑来源。`brand` 可用时先加载，再按需使用其视觉规范与资产记录方法；新系列或没有该 Skill 时可手动填写以下字段。

## 1. 风格表

| 字段 | 应记录的内容 |
|---|---|
| style_id / status | 例如 `series-v1`；草案或已确认，记录确认依据 |
| 媒介 | 钢笔淡彩、铅笔彩绘、水墨等，选定后保持一致 |
| 线条 | 轮廓轻重、线条密度、边缘处理；不要只写“高级手绘” |
| 色板 | 背景、轮廓、主色、点缀色及各自用途；色值作为设计目标 |
| 纹理与明暗 | 纸纹强度、是否晕染、阴影层数、整体对比 |
| 人物 | 造型比例、面部抽象程度；身份锚点由角色表具体定义 |
| 构图 | 背景复杂度、主体位置、景别范围、字幕留白 |
| 运动 | 允许的动作幅度、运镜、绘制显现方式、转场 |
| 后期 | 字幕字体和许可、字号/边距、年代条、地图标签、旁白音色 |
| 参考资产 | 可访问文件、用途、授权/来源、版本与确认状态 |
| 固定绘制规则 | 所有素材和镜头统一使用的视觉语言；程序绘制时复用相同参数，生图时转成完整提示词 |

### 可供确认的起步方案

以下仅是一个候选，不代表用户已接受：

- 二维墨线淡彩手绘，轮廓略有自然变化，保持清晰而不是随机抖动。
- 米白纸底；墨灰轮廓；低饱和靛蓝和土褐为辅助，少量朱砂作重点。
- 少层次阴影、简化背景、适度留白；人物不使用照片式皮肤或三维塑料材质。
- 一个镜头一个主要动作，优先静止机位或缓慢平移、缩放、分层视差、描边显现；不默认大幅旋转和连续变形。
- 固定纸纹、线条与随机参数，避免每帧重新随机绘制造成抖动；复用角色和器物资产。
- 年代、地名与字幕后期叠加；历史服饰与器物由具体时代资料约束。

可从这套候选绘制代表画面，风格锁定前必须由用户确认结果。素材可由本地绘图工具制作或从授权资产复用；若需外部付费生图，先取得调用授权。不要用著名作品、在世艺术家名字或影视 IP 代替可描述、可授权的风格规则。

## 2. 参考素材如何使用

区分三种素材，不混用：

1. **风格参考**：表达线条、色彩、材质；不是历史证据。
2. **身份/场景参考**：锁定同一角色、服饰或场景；仍须校验其历史依据。
3. **历史依据**：文物图录、文献或可靠复原研究；有证据价值不代表拥有复制或上传权。

每份参考记录用途、来源、可用权利、版本和人工确认状态。本地使用也需核查权利；若需上传到外部服务，另行确认授权及数据留存与使用条款。

先选少量代表性画面：人物中景、环境远景、器物近景。确认后将可用素材登记为 `asset_id`，记录本地文件、尺寸、透明通道、图层顺序、锚点和适用角色/场景。需要视差或局部动作时再拆背景、人物与器物；只做推拉平移时可直接复用整张插画。风格拼贴板用于审阅，不直接充当最终镜头画面。

不要把同一个虚构人物模板套到所有历史人物。无可靠肖像时使用明确的示意造型，不声称是真实容貌。

## 3. 历史主张表

| claim_id | 主张 | 来源及定位 | 核验状态 | 解说限定语 / 视觉处理 |
|---|---|---|---|---|
| C01 | 待填写的核心主张 | 作者、书名/机构、版本、卷页/展品号或 URL；未访问就写未访问 | 待核验 / 已核对 / 存在争议 | 例如改为“某史料记载”；无法支撑时删除 |

核查关键项：

- 年代、纪年换算与时序；不能把年份相同但地域不同的制度混为一谈。
- 人名、身份、头衔和生卒/任职时期是否相容。
- 服饰、发式、铠甲、器物、建筑、文字载体和技术是否属于该时空。
- 数字、直接引语与因果关系是否有依据；叙述者推断必须区别于史料原文。
- 地图须注明时间、依据和示意程度；不把现代边界直接当古代政区。
- 不把“首次”“唯一”“所有人都”等强断言当默认标题；确有依据才能使用。

核心主张未核验时允许输出标记清楚的提纲、分镜框架和待查清单，不标为事实审校通过。一个来源可以支持普通叙述，但有争议的重要结论应进一步交叉核对，或者降低确定性。

## 4. 分镜与动画时间轴

每镜最小记录：

```text
shot_id / style_id / character_ids / claim_ids
旁白、时代与地点、画布尺寸、帧率
时间：全片起止时间、镜头时长；旁白文件与实测时长
画面：固定绘制规则 + 身份/场景锚点 + 当前构图
素材：asset_ids、可访问文件、图层顺序、位置和锚点
动画：单一主要动作、运镜、关键帧、缓动与转场
字幕：文本、起止时间、字体、位置、安全边距；年代/地名/引用提示
输出：场景/时间轴或渲染脚本引用、合成参数与输出位置
风险：史实待核验项、素材裁切/图层穿帮/复杂运动风险
```

每镜绘制说明完整且自洽，不写“参考上一镜头风格”。角色锚点固定姓名/ID、外形、服装和道具；局部镜头只保留可见细节，不添加画面外的无关剧情。程序绘制复用相同风格参数；仅在实际生图时附带包含完整固定风格块的图片提示词。

动画计划须能转成当前渲染器的参数，而不是只写情绪或动作提示词。明确时间单位与局部/全局时间、位置坐标及缩放锚点；记录关键帧的起止值、缓动与图层遮罩。按实测旁白调整镜头和字幕，转场重叠时校正全片时长，避免音轨被截断或字幕越过镜头。

连续镜头只在确实同场景、同动作时承接构图和素材状态。换时代、换地点或解释性插图不强行承接；简单淡入淡出优先于无依据的画面变形。只有运镜时如实写明，不把平移缩放称为已完成人物肢体动画。

## 5. 审阅规则

优先阻止以下问题进入成片：史实关键错误、时代错置、身份明显漂移、未授权素材、未说明的虚构引语、误导性地图、旁白被截断或字幕错误。

细微纸纹、笔触差异可作为局部修正项，不用无休止重绘追求像素相同。色板相近不能替代人物、材质与运动检查。额外检查逐帧随机闪烁、图层错位、运镜裁掉主体、文字缺字、字幕越界、转场黑帧和旁白截断。

审阅结果按“通过 / 待修正 / 未验证”逐项记录。文件解码、时长/帧率/编码探测与完整播放分开验收；抽取首中尾帧只能作为补充。没有播放或听音能力的项目标为未验证。展示区域或简介应说明手绘示意和艺术复原的性质；实际使用 AI 生成素材时如实说明，具体位置遵守平台规则。
