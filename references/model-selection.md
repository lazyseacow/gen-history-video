# 手绘历史科普视频的模型选型

本指南提供候选与测试方法，不固定模型版本或价格，也不代表服务可用性或画质评测。实际采用前核对最新官方 API 文档、账号条件和小样效果。

## 1. 优先选择制作方式

建议先验证“已确认的手绘参考图 → 各镜头首帧 → 图生视频微动 → 配音与字幕后期”的路径。

- 图片模型负责绘画语言、角色和构图，视频模型负责在已确认首帧基础上运动。
- 文字、年份、地名、引用和地图边界由可控后期处理，不依赖视频模型正确绘制。
- 同一画风不要求生图、视频、配音来自同一家；但每多接一家服务，都增加凭据、计费和素材上传的管理成本。
- 先验证一个生成入口，不提前订阅多个套餐或搭建批量任务平台。

这一路径改善可控性，不保证跨帧完全一致；必须实际查看视频。

## 2. 服务候选

下表是调查入口，不是画质排名或已经实测的兼容列表。

| 服务候选 | 调查方向 | 首先核查什么 |
|---|---|---|
| 阿里云百炼 / 通义万相 | 国内云平台接入路线 | 账号与地区、图生视频 API、准确模型 ID、首帧/参考图条件、时长档位、价格与条款 |
| 火山方舟 / Seedance | 国内云平台的对照路线 | 同类条件；还要核对具体接入点、提交与轮询协议，不假定兼容其他厂商 |
| Google Gemini API / Veo | 账号、地区与支付条件合适时的国际服务路线 | API 开放范围、模型/参考图能力、地区、数据条款与费用 |

官方文档入口可能调整，使用时核对页面、版本与请求示例：
- [阿里云图生视频文档入口](https://help.aliyun.com/zh/model-studio/image-to-video-api-reference)
- [火山引擎视频 API 文档入口](https://www.volcengine.com/docs/82379/1520757)
- [Gemini API 视频文档入口](https://ai.google.dev/gemini-api/docs/video)

产品宣传页不能代替实际 API 文档。若已审阅的开源 Skill 稳定支持某个候选，可优先降低接入成本；若不能提供所需的首帧/参考条件，则换候选，不盲目坚持某个品牌。

## 3. 进入测试前的必要条件

- 准确 API 文档、可用账号与明确模型 ID；不用网页产品名猜请求字段。
- 用户选择的素材上传/留存政策及输出使用权可接受。
- 凭据有安全的读取方式，CLI/MCP/插件依赖已审阅。
- 已确认模型支持的比例、时长、清晰度、首帧或参考图条件。
- 金额与币种预算、价格或封顶依据已确认；调用次数和秒数另设限制。
- 提交、状态查询、下载分离；远端任务 ID 可以持久化和恢复。

满足执行条件前保持仅策划，不发真实生成请求。

## 4. 公平的小样测试

1. 先确定一个具体时代和一个有资料依据的简单场景，不一开始做多角色、群体运动或长对话。
2. 用户批准手绘参考画面。对照时尽量使用相同首帧、相同单一动作和相同输出目标；各服务只调整实际支持的参数。
3. 在预算内先测试一个短镜头，时长取模型支持且足以检查动作的档位。不预先承诺“几秒必然够用”。
4. 完整播放并辅助查看首、中、尾帧；记录实际调用、等待/下载情况与结果。
5. 先判断是否通过，再决定是否为第二个候选付费，不默认同时调用所有模型。

| 检查项 | 通过表现 | 失败表现 |
|---|---|---|
| 画风保持 | 线条、纸纹、平面设色贯穿全段 | 中途变成写实摄影、三维材质或显著换色 |
| 人物/器物 | 身份、服饰、关键道具可辨且稳定 | 变脸、换装、穿帮，出现不合时代的器物 |
| 动作与镜头 | 清楚完成单一轻动作，镜头可读 | 人物或物体持续变形、突然增减、无意跳切 |
| 内容准确 | 与审核过的画面和历史范围一致 | 为填满画面自动增加错误情节或符号 |
| 接入可靠 | 任务可查询、结果可下载，失败可定位 | 只提供网页操作、无法找回任务、超时后重复收费风险不明 |
| 成本 | 按确认价格/上限记录，返工可承受 | 单价不明、超出授权或失败计费条款不清 |

选定模型应基于接口、权利、预算与实际小样。将通过的模型版本、参考素材和生成参数记入单期记录；更换模型后重新验收。
