# 本地制作方式与小样标准

先根据现有环境选择能完成任务的最小工具组合，再做实际小样。本指南提供制作方法与核查项，不代表某个工具已安装、已通过兼容性测试或适合所有平台。

## 1. 默认制作路径

```text
已确认的风格与史实
  → 复用或绘制手绘插画
  → 角色、场景与器物图层
  → 旁白音频和字幕时间轴
  → 本地二维动画、运镜与转场
  → 合成和导出可播放视频
```

- 优先使用已有授权素材，或通过 SVG、Canvas、Pillow 等工具绘制；单张插画也能做轻运镜，不要求每镜都分层。
- 用关键帧控制平移、缩放、透明度、旋转、遮罩和路径显现；复杂肢体动作改用可控的分层关节或合理切镜，不承诺工具尚不具备的动画能力。
- 角色、纸纹、色板和随机参数固定后复用；字幕、年份、地名、引用和地图标签采用确定性排版。
- 声音优先用用户录音或已安装且授权适用的本地 TTS，按实测音频长度排镜头。没有可用声音来源时先明确缺项，可制作静音画面小样。
- FFmpeg 或已有动画渲染器负责输出视频。只要求策划时，不运行渲染或安装依赖；要求视频时，执行本地能力检查并尝试最小小样。

外部图片或语音服务仅是可选素材来源，不能成为本地制作的必经条件。确有需要时才进入第 5 节的授权检查。

## 2. 按职责选择工具

下表是工具类别与调查入口，不是固定依赖或已实测的兼容列表：

| 职责 | 可复用方式 | 首先核查什么 |
|---|---|---|
| 插画与图层 | 已有图片、SVG、Canvas、Pillow | 风格与授权、透明通道、画布尺寸、字体、素材分层是否够用 |
| 动画 | 已有脚本、FFmpeg 滤镜、Canvas 时间轴、已有 Remotion 项目 | 所需关键帧/遮罩/视差支持、帧率、渲染耗时、边缘裁切 |
| 旁白 | 用户录音、本地系统 TTS、已审阅的本地语音工具 | 中文和发音、音色与输出使用权、可用声音、音频时长及采样格式 |
| 字幕与包装 | SRT/ASS、SVG/Canvas/Pillow 排版、已有字幕组件 | 字体许可与中文覆盖、时间戳、换行、安全边距；所需字幕滤镜是否可用 |
| 合成与编码 | FFmpeg、现有剪辑/渲染工具 | 可执行路径、所需编码器/滤镜、音画同步、像素格式、容器与播放器兼容性 |

官方资料可按实际采用的组件查阅：
- [FFmpeg 文档](https://ffmpeg.org/documentation.html)
- [Pillow 文档](https://pillow.readthedocs.io/)
- [Remotion 文档](https://www.remotion.dev/docs/)

优先采用已有可用组合；仅为几秒小样不引入大型工程。不要硬编码某台机器的工作目录、声音名称或字体路径；先发现实际资源，再记录本次选择。

## 3. 视频渲染前的必要条件

以下条件适用于动画小样或整期制作。仅静态风格小样时核实绘图、素材权利和风格，交付代表图与风格记录；音频、字幕及视频编码检查不适用。

- 核心史实与复原范围已按当前阶段核验，素材来源和使用权有记录，代表画面已确认。
- 本地绘制和渲染工具可运行，所需库、字体及输出空间已核查；新增依赖的安装范围已获同意。
- 已确定画布尺寸、比例、帧率、镜头时长、关键帧和字幕安全区，时间单位清楚且与实际渲染器一致。
- 旁白音频可读且时长已测量；静音小样明确标注，未提供音轨不能声称配音完成。
- 核查实际合成需要的编码器和滤镜。例如使用 ASS 烧录时需字幕渲染能力，不能只因存在 FFmpeg 就认定相关功能可用。
- 输入素材、场景/时间轴、执行命令、工具版本、日志和输出位置可追踪；失败可从已有素材或片段恢复。

以 MP4 交付时可优先考虑 H.264、`yuv420p` 及有音频时的 AAC，但须验证当前编码器支持和目标播放器；换用其他格式时说明兼容性。不能只靠文件扩展名认定编码正确。

## 4. 最小小样测试

1. 选一个具体时代、一个有资料依据的简单场景和一个主要动作，不从多角色群体运动或长对话开始。
2. 用户确认代表画面。复用相同素材和风格版本，固定随机参数；选择能代表整期的运镜、字幕和声音形式。
3. 先渲染一个短镜头，时长按实际旁白或审阅目标确定。先验证画面、字幕和音频可合成，再扩展整期。
4. 检查文件可解码及尺寸、帧率、时长、编码和音轨；查看首/中/尾帧，并完整播放检查运动、声音与字幕。
5. 记录通过项、修正项、未验证项和实际渲染耗时。小样未通过时先修素材、时间轴或合成参数，不盲目增加复杂度。

| 检查项 | 通过表现 | 失败表现 |
|---|---|---|
| 画风保持 | 线条、纸纹、平面设色贯穿全段 | 纸纹逐帧随机、明显换色、插画缩放后失真 |
| 人物/器物 | 身份、服饰、关键道具可辨且稳定 | 角色混用、分层错位、出现不合时代的器物 |
| 动作与镜头 | 实现预定动作，推拉平移平稳，边界合理 | 未执行关键帧、穿帮、裁掉主体、无意跳切或黑帧 |
| 内容准确 | 与审核过的画面和历史范围一致 | 标签、地图或新加素材引入错误情节 |
| 配音与字幕 | 旁白完整、字幕对齐且可读，响度适当 | 音频截断、错字、时间错位、字体缺字、文字越界 |
| 输出可靠 | 文件可解码，时长/比例/帧率符合目标，可按记录复现 | 仅有图片或空文件、错误帧率、音画不同步、过程不可复现 |
| 执行范围 | 小样范围和资源使用符合约定 | 擅自安装、更改全局设置或发起付费调用 |

完整播放与声音检查须单独记录；首中尾帧、编码器成功退出或文件存在均不能替代视听验收。更换素材、工具版本或渲染参数后重新验收受影响部分。

## 5. 可选的外部素材服务

只有确需外部图片或语音服务时才检查以下事项，本地制作不要求填写这些字段：

- 准确 API 文档、可用账号、服务/模型 ID 和所需输入输出能力。
- 素材上传、留存政策及输出使用权可接受；凭据通过安全机制引用，不读取或输出密钥。
- 金额与币种预算、单价或可核实封顶依据已确认；调用次数和音频秒数另设限制，不能替代金额预算。
- 工具和依赖已审阅。异步提交保存远端任务 ID，状态查询和下载沿用原任务；超时不自动重复付费提交。

不满足条件时继续使用可用的本地路线，或明确列出待补素材，不自动订阅套餐、更换付费服务或扩大调用范围。
